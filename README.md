# Cron_Scribe 🎯
![CI](https://github.com/realMNohgee/Cron_Scribe/actions/workflows/ci.yml/badge.svg) ![Python](https://img.shields.io/badge/python-3.9%2B-blue.svg) ![License](https://img.shields.io/badge/license-MIT-blue.svg)

**Natural language to cron expression converter and validator. Translate 'every Monday at 9am' into cron syntax and back.** Zero dependencies, pure Python stdlib.

> Part of the production suite — scheduling.

## One tool, many domains

| Domain | What Cron_Scribe does for you |
|---|---|
| ⏰ DevOps | Build cron expressions from plain English — no more man 5 crontab |
| 🤖 Automation | Validate schedules before deploying cron jobs |
| 📅 Operations | Calculate next N run times, explain existing crontabs |
| 🧠 Agentic AI | Agents translate user-facing schedules into machine-readable cron |

## Install

```bash
git clone git@github.com:realMNohgee/Cron_Scribe.git
cd Cron_Scribe
python3 cron_scribe.py --help
```

# parse, build, natural, validate, next
